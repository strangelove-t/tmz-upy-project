# Recursos del reporte del alumno

- `logo_upy.png`: emblema de la Universidad Politécnica de Yucatán en blanco
  con fondo transparente; se usa sobre la franja morada del encabezado.
- `fonts/Lato-Regular.ttf`, `fonts/Lato-Bold.ttf`, `fonts/Lato-Black.ttf`:
  tipografía Lato © 2010-2011 Łukasz Dziedzic, bajo SIL Open Font License 1.1
  (`fonts/OFL.txt`). Se incluyen para que el PDF se vea igual en cualquier
  computadora, incluida la instalación en Windows.

Paleta institucional (`src/tamizaje/student_report.py`):

| Rol | HEX | Uso |
|---|---|---|
| Morado principal | `#5B0A8A` | Encabezado, títulos y recuadro de contacto |
| Naranja de acento | `#FDA20C` | Sólo acentos sobre morado (contraste 5.6:1) |
| Casi negro | `#1B1319` | Texto |
| Fondo | `#FFFFFF` | Página |

El naranja no se usa como texto sobre blanco (contraste 2:1) ni en los
resultados, para no confundirlo con el ámbar de "Dar seguimiento". Los colores
del semáforo son independientes de la marca.
